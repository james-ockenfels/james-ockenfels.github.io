Flipper-32: Building My Own Flipper Zero on an ESP32

I built a Flipper Zero-inspired IR remote tool using an ESP32, an OLED screen, and a handful of components, here's how it came together.

If you're into cybersecurity or hardware hacking, you've probably heard of the Flipper Zero. a pocket-sized multi-tool that can interact with all kinds of wireless protocols. It's a cool piece of hardware, but it's also not cheap. So I decided to build something inspired by it using an ESP32, which I already had lying around. The result is the Flipper-32: a DIY IR remote capture and transmit device with a small OLED display, a MicroSD card slot for storage, and four buttons for navigation.

The project is fully open source under the GPL-3.0 license and is up on my GitHub if you want to build one yourself.

What It Does

The Flipper-32 focuses on infrared (IR) functionality. It can receive and decode IR signals from remotes and other devices, and transmit them back. It supports a solid range of protocols out of the box:

  • NEC, NECext, NEC42, NEC42ext
  • Samsung32
  • RC6, RC5, RC5X
  • SIRC, SIRC15, SIRC20
  • Kaseikyo

RCA and Pioneer aren't supported yet, and RAW data capture is something I'm planning to add down the line. Bluetooth functionality is also on the roadmap.

What You Need to Build One

The component list is pretty minimal and all of it is cheap and easy to source:

  • ESP32 microcontroller
  • 64x128 4-pin OLED display
  • MicroSD card to SD card adapter
  • 4 push buttons
  • IR LED
  • Breadboard or solder board and wires
  • Optionally: a small battery connected to VIN and GND with a switch for portable use

Software Setup

To get the code onto your ESP32 you'll need Arduino IDE and the following libraries installed via the Library Manager:

  • Adafruit GFX Library (1.11.11)
  • Adafruit SSD1306 (2.5.13)
  • SD Library (1.3.0)
  • ezButton (1.0.6)
  • IRMP (3.6.4)

Once those are installed, download ir-parsed-testing.ino and PinDefinitionsAndMore.h from the repo. Open the .ino file in Arduino IDE, add a new tab, paste in PinDefinitionsAndMore.h, and make sure the filename matches. Then plug in your ESP32, select the right board and port, and hit Upload.

Wiring It Up

Here's how everything connects to the ESP32:

SD Card

  • Pin 1 → GPIO 15
  • Pin 2 → GPIO 23
  • Pin 3 → GND
  • Pin 4 → 3.3V
  • Pin 5 → GPIO 18
  • Pin 6 → GND
  • Pin 7 → GPIO 19

OLED Display

  • VCC → 3.3V
  • GND → GND
  • SDA → GPIO 21
  • SCL → GPIO 22

Buttons

  • Button 1 → GPIO 12 (Plus)
  • Button 2 → GPIO 14 (Minus)
  • Button 3 → GPIO 27 (Equal/Select)
  • Button 4 → GPIO 26 (Back)

Make sure each button is wired so that ground and the pin are only connected when the button is pressed.

IR LED

  • + → GPIO 4
  • - → GND

What I Learned

This was my first real hardware project that combined embedded C++ programming with physical components. Getting the IR library working correctly and parsing the decoded signals into something usable took the most trial and error. The Serial Monitor in Arduino IDE became my best friend for debugging. I also learned a lot about how IR protocols actually work, there's more structure to a TV remote signal than you'd think.

Adding the battery and power switch at the end was a small touch but made the whole thing feel like an actual device rather than a breadboard experiment. The project has 2 stars and a fork on GitHub so far, which is pretty cool to see.

If you want to check out the code or build your own, the full repo is on my GitHub. Happy hacking! 🚀
