Building This Website From Scratch

How a high school capstone project turned into the portfolio site you're reading this on right now.

This website started as a capstone project for a web development class I took at Indian Hills Community College (IHCC) during my junior year of high school. The assignment was to build a personal portfolio site from scratch using HTML, CSS, and JavaScript, no templates, no website builders, just code. I ended up getting a 100% on it, which I was pretty happy about. But more than the grade, it was the first real project I built and actually deployed, and that felt like a big deal.

Why I Built It

The short answer is that it was required for class. But honestly, I was already interested in tech and this gave me a reason to sit down and learn how websites actually work under the hood. I'd messed around with code before, but never built something with real pages, real navigation, and a real structure. The capstone pushed me to do that properly, and I found that I genuinely enjoyed it.

What I Used

  • HTML & CSS for structure and styling
  • JavaScript for interactivity (like the mobile hamburger menu)
  • Visual Studio Code as my code editor
  • Git and GitHub to version-control and host the project

How I Kept It Updated

My workflow throughout the project was pretty simple. Whenever I made changes I was happy with, I'd stage everything, write a commit message, and push it up to GitHub: 

git add .
git commit -m "Updating files"
git push -u origin main

It's not the most descriptive commit history in the world, but it got the job done and kept everything backed up as I went. Using Git from the start was one of the better habits I picked up from this project.

What the Original Site Looked Like

The version I submitted on November 10th, 2024 had the core pages, a home page, an about me section, a projects page, an education page, a goals page, and a contact page. The design used the dark navy and teal color scheme you still see today. That part I was happy with from the start, so it stuck around.

How It's Changed Since Then

After the class ended and the grade was in, I kept coming back to the site and adding things. The original submission didn't have everything I wanted, it was scoped to what I could finish by the deadline. Since then I've added a downloads page where visitors can grab my resume and Google certificates, and most recently a blog (which you're reading right now). Each new page has been a chance to practice and try things I didn't know how to do when I first built the site.

What I Took Away From It

Building this site taught me that the best way to learn web development is to just make something real. Tutorials are fine, but nothing forces you to actually problem-solve like having a project with a deadline and your name on it. I also learned that a site is never really "done", there's always something to improve, add, or rethink. That mindset has stuck with me, and this site is proof of it.
